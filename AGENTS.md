# Working on this lab

Read README.md, docs/contract.md and docs/architecture.md before changing behavior.
All repository prose, comments, commits and issues are in English. Use fictional data.
Keep this scoped to an intervention-request lab; no payments, emails, authentication,
queues, stock, multi-tenancy or deployments. PostgreSQL owns concurrency guarantees.
Keep every commit focused and buildable; run the relevant checks before committing.
Use exact dependency versions and the lockfile. All apps and original code are MIT;
retain third-party licenses. CI must check PRs and main with real PostgreSQL and browsers.
Never commit secrets or private internal notes. Scan changes and Git history before pushing.
Record actual results, screenshots and limitations against an examined revision or tag.
Never move a published tag. GitHub delivery does not authorize deployment or LinkedIn posts.
